The Picnic Table Inventory & Management System was developed to provide an organized way to maintain picnic table records using a relational database.

The project demonstrates practical experience with:

C programming
SQL databases
Relational database design
Primary and foreign keys
SQL queries
Data management
Database relationships

Features:
Store picnic table information in a structured database
Add new records
Search and retrieve existing records
Update picnic table information
Delete records
Track picnic table inventory
Execute SQL queries to retrieve relevant information
Maintain relationships between database tables using primary and foreign keys
